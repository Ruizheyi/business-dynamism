5. WHAT THIS CHANGES
==============================================================================
  BEA coefficient zero too -> the null is now robust to TWO
     independent exposure measures, which is a stronger claim
     than the one the README currently makes.
  BEA coefficient nonzero  -> the earlier null came from sorting
     sectors on the wrong variable. That is a real finding and the
     gradient section has to be rewritten around it.
  equipment placebo nonzero -> whatever is going on is not specific
     to intangibles.
